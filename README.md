# A little more Mounir

An interactive phone-style personal website with Messages, Photos, Maps, Reminders and a playful Buy or Sell guessing game.

## Run locally

Open `index.html` in a browser. Images, styles and scripts are embedded; no build step or dependencies are required.

## Hosting

In repository Settings → Pages, choose Deploy from a branch, then `main` and `/ (root)`.

Messages open WhatsApp with a prepared draft. The visitor confirms sending in WhatsApp.
